# Security Policy

## Supported version

The `main` branch and the currently deployed portfolio are supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Contact the repository owner privately through the contact details published on the portfolio website and include:

- the affected page, component, workflow, or dependency;
- clear reproduction steps;
- the security impact;
- any suggested remediation, if known.

Do not include credentials, tokens, private user data, or exploit payloads in public GitHub content.

## Security practices

This project follows least-privilege GitHub Actions permissions, deterministic dependency installation, automated dependency updates, static analysis, no client-side secrets, and privacy-first personalization. Visitor search text used for personalization is not persisted or sent to analytics by the portfolio code.
